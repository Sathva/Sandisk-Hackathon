1. Executive Summary & Core Contributions

In high-volume semiconductor manufacturing, each silicon wafer yields thousands of integrated circuit dies tested sequentially. While conventional fab testing screens dies solely through die-level parametric electrical measurements, post-stress silicon failures are driven by multi-scale phenomena: macro wafer-scale thermal and chemical chamber gradients, local defect clustering, and micro-scale internal cell degradation captured in high-dimensional sub-die block readings.

The Core Finding: Sub-die block readings provide a +0.04802 test AUC-PR lift (+9.73% relative gain) over die-level features under an identical 3-engine tree stack. In our operational screening audit, Model B rescued 795 true post-test failures that were completely invisible to die-level parametric tests alone, directly fulfilling the primary hackathon objective.

2. Semiconductor Problem & Manufacturing Context

In flash memory and advanced integrated circuit fabrication, 300mm silicon wafers undergo hundreds of sequential photolithography, plasma etch, chemical-mechanical planarization (CMP), and thin-film deposition steps. Yield excursion detection is complicated by the fact that test data naturally spans three vastly different physical and geometric resolutions:

1. Wafer Topography

Macro-scale variations: radial thermal gradients, edge gas-flow turbulence, and wafer-wide chamber baseline drift. Spans 100mm–300mm.

2. Die-Level Parametrics

Mid-scale probe electrical tests: 500 parametric measurements capturing transistor threshold voltages, leakage currents, and sheet resistances.

3. Sub-Die Block Readings

Micro-scale internal readings: dense sequences of 2,000 continuous readings capturing cell-to-cell variability and localized gate stress anomalies.

2.1 The WM-811K Real-World Fab Foundation

The spatial coordinates, grid dimensions, and pre-existing defect patterns in this benchmark are derived from the industry-standard WM-811K wafer map dataset, comprising real 300mm silicon wafers from high-volume production fabs. Synthetic parametric measurements and sub-die block readings were algorithmically synthesized on top of this spatial topology via generate_data.py.

Figure 2: Sample Wafer Topography from the WM-811K Foundation. Green indicates passing dies; Red indicates pre-existing known defects (old_label = 1); Orange indicates newly failed target dies (old_label = 0 and label = 1).

2.2 The Target Definition & The "Golden Rule"

To eliminate evaluation leakage and reflect actual fab screening operations, dies are strictly partitioned into two disjoint populations:

  • Eligible Population (old_label == 0): Dies that were functional and healthy prior to test. In unseen test silicon, 96.44% remain healthy (Pass, label=0) while 3.556% newly fail (Defect, label=1). This 3.556% minority failure rate is the true prediction target.
  • Ineligible Population (old_label == 1): Dies already marked as defective from incoming inspection. In all submissions and production flows, these dies are trivially hardcoded to predicted_label = 1. They are strictly excluded from model loss calculations and threshold tuning.

3.1 Strict Zero-Leakage Guarantees

1. Complete Wafer-Level Isolation: All splits are grouped strictly by wafer_id. No dies from the same wafer appear across train and test sets, preventing spatial leakage.
2. Freezing Before Evaluation: Model architectures, feature scalers, PCA projectors, shrinkage LDA vectors, decision thresholds, and ensemble weights were permanently frozen on dev_val before test ground-truth labels were loaded.
3. Blind Prediction Generation: Unseen test predictions were generated strictly from validation_features.parquet and validation.csv (which contain zero labels) and written to disk before evaluation scripts were executed. These two files describe the same 200 wafers and the same 208,264 dies as test.csv: validation.csv is test.csv with the label column removed. Verified identical row-for-row on wafer_id, die_row, die_col, old_label and all 500 parametric measurements. Inference is therefore genuinely blind, while scoring uses the withheld ground truth for those identical dies — which is why the same population appears in the table above with a stated failure count of 6,584.
4. Defensibility on Synthetic Data: The parametric and block signals were generated synthetically. Consequently, our statistical attributions describe mathematical patterns discovered by models, not established physical fab equipment causality.

3.2 Handling Extreme Imbalance (3.556% Failure Prevalence)

A naive model that predicts "PASS" for all dies achieves a deceptive 96.44% accuracy but detects 0 failures, leading to catastrophic field failure rates. To solve this:

  • Class Weighting: Loss functions employ cost-sensitive weights (scale_pos_weight = 26.07), penalizing missed defects 25× more heavily than false alarms.
  • Metric Alignment: Evaluation is conducted primarily on Precision-Recall AUC (AUC-PR) and F1 Score on the positive minority class, ensuring optimization focuses exclusively on defect discrimination.

4. Multi-Resolution Feature Architecture

To systematically extract predictive signal from all available data layers, we designed a structured 1,280-dimensional feature taxonomy spanning seven physical and statistical domains:

Physical Feature Domain Count Engineering & Mathematical Formulation Representative Features
1. Parametric (Die-Level) 500 Raw electrical probe test measurements capturing transistor threshold voltage, sheet resistance, and junction leakage. feature_1 to feature_500, pca_comp_1
2. Spatial Context 19 Neighborhood defect densities in 3×3, 5×5 windows; normalized radial distance; perimeter and edge flags. radius, distance_to_edge, old_fail_count_5x5, old_fail_density_3x3
3. Block Dynamics (Sub-Die) 36 Summary statistics across 2,000 sub-die readings: rolling window means, burst elevation excess, quantiles, and wavelet energy. max_rolling_mean_400, burst_excess_350, block_q75, block_mean_top200
4. Wafer-Relative & Detrended 503 Wafer-conditional spatial surface subtraction via 2nd-order polynomial ridge regression; within-wafer Z-scores and percentile ranks. dt_feature_1 to dt_feature_500, wdev_pc01, wrank_lda
5. Manifold & Projections 30 Bayes-optimal shrinkage LDA discriminant direction (Sreg-1(μ1-μ0)), detrended PCA components, and dispersion context. wctx_ldadt_std, pca_01, lda_score, wdev_pca_01
6. Bilinear Interactions 180 Cross-resolution multiplicative products coupling macro electrical drift with micro sub-die block burst amplitudes. inter_pc1_x_roll400, inter_pca01_x_roll350, inter_pc1_x_edge_density
7. Coordinates & Geometry 12 Wafer grid coordinates, polar angle θ, and Chebyshev polynomial basis terms. die_row, die_col, radius_squared, normalized_col

4.1 Why Multi-Scale Engineering Resolves Marginal Dies

The Limitation of Whole-Die Parametrics: In production silicon, wafer-to-wafer thermal and chemical drift shifts the electrical baseline between fab chambers. Consequently, a die with marginal electrical measurements may be completely healthy in a cold chamber but failing in a hot chamber. By computing within-wafer standardized deviations (wdev_*) and detrended residuals (dt_*), our pipeline decouples localized defect detection from wafer-scale baseline drift.

4.2 The Cross-Resolution Bilinear Breakthrough

Defects rarely manifest in a single measurement channel. A die undergoing subtle electrical parametric drift is exponentially more vulnerable if it also exhibits internal sub-die block reading bursts. Creating bilinear products (such as inter_pc1_x_roll400) provides decision trees with explicit interaction axes without requiring deep combinatorial tree splits.

5. Official Model A: Die-Level + Spatial Benchmark

As mandated by the official problem statement, Model A establishes the primary die-level baseline. It strictly excludes all sub-die block readings, predicting failure probability purely from 519 features:

  • 500 Parametric Electrical Measurements: Transistor and interconnect electrical test features.
  • 19 Spatial Context Features: Normalized radius rnorm, perimeter edge flags, and neighborhood defect densities.

5.1 Model A Architecture: 3-Engine Tree Stack

To eliminate algorithmic bias, Model A is implemented both as individual tree boosters and as an ensemble stack combining three diverse gradient boosted decision tree paradigms:

  1. LightGBM A: Leaf-wise asymmetric histogram trees (num_leaves=63, scale_pos_weight=26.07).
  2. CatBoost A (GPU): Symmetric oblivious decision trees on GPU (depth=7, l2_leaf_reg=6.0).
  3. XGBoost A: Depth-wise histogram trees (max_depth=6, subsample=0.80).
  4. Model A 3-Engine Stack: Weighted blend optimized on validation data (0.50 × LGB + 0.30 × CB + 0.20 × XGB).

13.1 Exact TreeSHAP Attribution Methodology on CatBoost GPU

Direct Tree Attribution vs. Rank Ensembles:
Model F's final ensemble blends predictions in empirical rank space [0, 1]. Because the rank transformation is non-linear and non-additive, averaging or summing SHAP values across models blended in rank space is mathematically invalid.
Our Solution: Local explanations are extracted directly from CatBoost GPU, Model F's dominant individual tree engine (0.6226 test AUC-PR), where exact TreeSHAP is mathematically guaranteed to be strictly additive in the model's raw log-odds margin space.

13.2 Mathematical Verification of Margin Additivity

TreeSHAP decomposes the model's raw formula margin into signed feature contributions:

raw_margin(x) = base_expected_value + ∑j=11280 SHAPj(x)

Across all 25,013 evaluated test dies, the maximum numerical error between the reconstructed margin and the model's true output is:

Max Additivity Error = 7.99 × 10⁻¹⁵   (Strictly Additive in Log-Odds Space: TRUE)

Score Entity Scale Mathematical Meaning Can SHAP Values Sum to This?
